Files:

- logo.svg: brand logo

To publish with Vercel:
1. Upload index.html and logo.svg to the root of your GitHub repository.
2. In Vercel, choose Add New > Project and import the repository.
3. Keep Framework Preset as Other and leave Build Command and Output Directory empty/default.
4. Deploy.
